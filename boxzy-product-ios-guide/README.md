# BOXZY iOS 最终 UI 与产品说明

2026-10-13 前端交付版。包含 38 个页面的老 UI / 最终 UI 对比、UI 参数标注和产品说明，以及用户名异常状态、提现成功与失败样式。

## 离线使用

1. 克隆仓库，或通过 GitHub 的 Code → Download ZIP 下载并解压。
2. 用浏览器打开 `BOXZY-iOS-PRODUCT-GUIDE.html`。
3. 保留同级 `assets` 文件夹；所有 81 张图片均在本地，无外部资源依赖。

## 开发阅读顺序

先阅读文档顶部的统一颜色、字体、按钮、间距、商品图片及自适应规范，再按页面查看最终 UI、修改点和交互规则。老 UI 仅用于对比，可能保留已删除的历史内容。

本次已移除最终 UI 中的邀请和推荐码内容，并更新账户页及帮助中心截图。

截图中的金额、概率、奖池和税费为示例，正式配置以服务端为准。文档明确区分最终设计与当前实现：提现成功/失败样式已经补充，原生结果分支和真实业务仍需接入。
