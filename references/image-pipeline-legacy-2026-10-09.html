商品链接取图与超分

Image URL 接受商品详情页链接或图片直链。目标是得到一张经确认、可长期使用的商品图片，并准确关联当前 SKU。

输入链接 → 找到对应商品主图 → 下载原图 → 超分与质量检查 → 运营确认 → 关联当前 SKU → 保存草稿／发布。

本页为补充开发需求。当前离线 HTML 只实现图片上传与浏览器可访问的图片直链下载；商品页解析、服务端存储和超分 API 尚未接入。现有截图中的 Image URL 是入口位置，不代表下面的处理流程已经上线。

1. 入口与适用范围

功能说明：新增 SKU、编辑 SKU、Excel 导入共用同一套图片处理服务。保留模板 Image URL 列名，允许填写商品页链接或图片直链；上传本地图片可跳过网页解析，但仍进行格式、尺寸和质量检查。市场价、进货价、权重与分类继续由运营填写，本功能不顺带抓取或覆盖它们。

交互逻辑：单条表单填写链接后点击 Fetch image，在当前弹窗内显示 Finding image… → Downloading… → Enhancing… → Ready to review。有多张候选主图时先选图，再处理所选图片。处理后展示原图与处理图、实际像素尺寸和商品来源名称；运营核对后点 Use image。不增加独立页面。

异常状态：未填写链接时 Fetch image 不可点；处理期间禁止重复请求。新 SKU 无有效图片时不能添加。编辑旧 SKU 时原图继续保留；新链接失败不得悄悄连同旧图一起提交，需 Retry、Upload image 或明确 Keep current image。

2. 先找到正确图片，再下载

功能说明：商品页不是图片文件，不能直接作为图片地址交给超分模型。服务端先判断实际响应类型：可解码的图片走直链流程；网页走对应站点的商品解析流程。

交互逻辑：对于已适配站点，读取当前商品 ID 对应的商品数据／主图；优先使用站点公开提供的原始尺寸图片。通用网页可读取 Product 结构化数据中的 image，或核对商品相关的主图元数据；不能盲取网页第一张图、站点 logo、广告或推荐商品图。动态页面在普通读取无结果后，由服务端浏览器渲染再提取该商品图片；不能凭空猜 API 或改 URL 参数声称已获得高清原图。

提取来源商品名仅用于核对；运营已填名称不被覆盖。未填时可以选择采用来源名称，但仍需确认商品版本、语言、包装款式与 SKU 一致。无法确定唯一主图时让运营选图，不自动随机选一张。

异常状态：无图片、页面不支持、403／404、登录限制、超时分别反馈原因。提示 No product image found. Upload an image instead.；保留其他表单输入。不绕过站点访问限制。

3. 下载到自己的存储，再运行模型

功能说明：“获取本地图片”指下载到服务端受控临时文件／自有对象存储，不是要求运营保存到电脑 Downloads。前台最终读取自有图片地址，不长期依赖第三方网站外链。

交互逻辑：下载、真实解码、检查格式与尺寸后保存只读原图；计算文件内容哈希，再提交超分任务。处理完成后保留原图、高清主图及列表缩略图。上传文件与直链下载进入同一流程。模型只接收校验后的图片资源，不能让模型服务自行抓任意商品页。

异常状态：文件扩展名与实际格式不一致、无法解码、尺寸超限、下载中断、存储失败均阻止本张图就绪。抓取仅允许 HTTPS 公网目标，每次重定向重新检查，拒绝内网／本机地址；限制响应字节和解码像素，避免无限读取。具体文件上限、像素上限、超时和重试次数由后端配置并联调确认，不套用原型的 5 MB 限制。

4. 复用已用过的超分方案

已核实：项目脚本 tools/asset-upscale/prepare_hd.py 使用 Real-ESRGAN x4plus，执行器为 realesrgan-ncnn-vulkan。既有 21 份处理记录中，商品 WebP 图采用 4 倍输出，并将 60% 模型结果与 40% 普通放大原图混合；透明通道从原图独立缩放保留。

已附 既有处理脚本和 模型权重哈希／历史处理依据。脚本是历史素材批处理参考，不能直接当成生产服务启动脚本。

开发建议：服务端将这套处理封装为内部异步图片 API，复用模型、权重文件及预处理／后处理参数。当前证据是本地执行器和产物记录；没有证据确认之前某个云端 API 的供应商、模型版本或调用地址，不能写成已有接口。若采用外部托管 API，先确认其模型版本、参数支持和样片结果，再确定供应商。

模型参数：是什么、怎么算、用于什么

模型：realesrgan-x4plus，通用图片超分模型；不用动漫专用版本自动重绘商品包装。参考 官方项目与 官方 NCNN 实现。

放大倍率 4：输出宽度等于原宽度乘以 4，输出高度等于原高度乘以 4，像素总数为原来的 16 倍。用于增加展示尺寸，不代表可辨识细节提升 4 倍。

模型混合比例 60%：先将原图以 Lanczos 等比例放到同尺寸，再将模型输出按 60%、普通放大原图按 40% 混合。用于减轻过锐与伪细节；不是“清晰度分数 60%”。这是既有商品图参数，生产先按此做样片基线，质量不过关则换更好的原图。

分块 128、线程设置 1:1:1：沿用原脚本的推理资源设置，控制分块和流水线资源，不是图片清晰度指标。部署机器如需调整，应保留样片对比，不能将硬件参数当成业务字段让运营填写。

版本固定：记录模型名、执行器版本、模型权重哈希、倍率和混合比例；去重缓存使用原图内容哈希加处理版本。相同地址内容变化需重新识别，不能只按 URL 永久复用旧图。

5. “足够清晰”的验收方式

功能说明：验收同时看尺寸和商品真实性，不能只检查“生成文件成功”。超分不能保证恢复原图已经丢失的文字与细节。

建议上线基线，待样片验收确认：详情图长边至少 1600 像素，保持原始宽高比、不裁切商品；超分最多一轮 4 倍。原图本身达到要求且清晰时直接保留高清原图，不为流程重复超分。列表缩略图从通过验收的主图生成。

以相同展示尺寸对比原图和输出图：商品型号、卡面文字、数量、Logo 与包装结构不得被改变；无明显涂抹、锐化白边、分块接缝和色偏；原有透明背景保留。运营在详情展示尺寸和 100% 放大下确认图片仍是对应商品。尺寸达标只是自动检查，商品正确性仍需人工核对。

异常状态：4 倍处理后仍不达标、或模型改变包装文字／细节时标记 Needs review，要求换更高清原图或上传正确图，不能循环放大来凑尺寸。模型失败显示 Image enhancement failed. Retry or upload another image.，不得显示 Ready；已经合格的高清原图可走明确的原图通过路径，并记录“未超分”，不能假称超分成功。

6. 图片怎样与 SKU 一一对应

功能说明：每个 SKU 当前配置只选用一张商品主图。关联依据是 Box ID + SKU ID + image_asset_id，商品名称只用于人类核对与可读文件名，不能作为匹配键。同名商品、重命名与多个 Box 不会因此串图。

交互逻辑：未保存新 SKU 先绑定临时记录 ID；Use image 仅选中本次处理结果。Add to current edits／Apply changes 将名称和图片资源引用一起写入当前编辑；Save draft 才持久化草稿关联，Publish 才更新线上版本。首次保存生成正式 SKU ID 并迁移关联。处理服务可以提前存临时文件，但不能提前改线上商品图片。

更换图片生成新资源，不覆盖旧文件；已发布历史版本保留自己的图片引用。Cancel 撤销当前未保存的选图，线上图不变。无任何草稿／版本引用的临时资源按清理策略回收；被历史版本引用的图不能一起删除。跨 Box 可复用不可变图片文件，但各自 SKU 的图片选择、配置和库存独立。

开发需保存的字段及接口结果

运营输入：Image URL（商品页／图片来源地址）、Product name、选中的候选图。名称仍是业务字段，不自动当作文件键。

系统记录来源：输入链接、站点名、来源商品 ID、来源商品名、最终下载地址、抓取时间；均只读，用于追溯是否取对商品。

系统记录资源：image_asset_id、原图与处理图存储键、实际宽高、格式、字节大小、原图哈希、模型版本与参数、审核选择。最终公开展示 URL 由资源服务返回，不能用运营电脑路径代替。

任务接口建议：创建任务传入 Box ID、SKU ID 或临时记录 ID、来源 URL、当前表单修订号与幂等请求 ID；返回任务 ID。查询／回调返回阶段、候选图、预览资源、尺寸和明确错误码。最终保存只提交服务端已就绪的 asset ID，服务端校验归属、处理状态和表单修订号，不信任浏览器自称“已超分”。具体路由与鉴权接入待后端确定。

防止异步串图：换链接、换 SKU、关闭弹窗或重新上传后废弃旧任务结果；旧请求即使完成，也不能覆盖当前新选择。同一个确认请求重试不产生重复资源或重复 SKU。

7. Excel 导入／导出同步规则

功能说明：沿用已经确认的六分类模板，不新增运营必填列。Image URL 新行可填商品页或图片直链；导出该列使用已转存的图片地址，方便再次导入，来源商品页保留在系统追溯信息里。

交互逻辑：先校验表格字段和 SKU 归属，再逐行取图／超分。显示已处理数与总数；有多候选、商品名称不符或质量待确认的行，需展示该行名称、图和 Excel 行号供确认。所有行通过且需要确认的图片已确认，才显示 Apply to current edits；仍按整份一次性应用，不直接保存草稿或发布。

已有 SKU 的链接为空或未改时保留已有图；自有已就绪资产验证归属后复用，不重复超分。换成新的外部链接才启动新任务。不能以相同商品名覆盖其他 SKU 的图片。

异常状态：任一图片失败时整批不应用，现有数据保持不变；逐行显示下载失败、找不到主图、超分失败或等待人工确认。可重试失败项，已完成资源只有在来源、处理版本和配置修订仍一致时才可复用。取消导入后旧回调不再写入数据。文件和图片资源均就绪只是“可以应用”，不等于已发布。
